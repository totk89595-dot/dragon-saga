ДРАКОНЬЯ САГА: ХРОНИКИ ФРАИЛЕН · v0.4 Visual Update
Обновление 3D-рендера версии 0.3. Оригинальные процедурные модели, без заимствования ассетов Dota 2.
Сохраняются четыре главы, механики, ключ сохранения frailen-save-v2 и управление. Новое: карта мягких теней, материалы земли и воды, новая геометрия экипировки, волосы, плащи, оружие, детали пауков, растительность и руины, приближенная камера.

УСТАНОВКА: распаковать ZIP, загрузить все файлы непосредственно в корень существующего репозитория dragon-saga (ветка main), заменить одноименные. Settings > Pages > Deploy from a branch > main / (root), если еще не настроено. Открыть существующий адрес GitHub Pages. Если старая версия, обновить Safari и перезапустить приложение. Не удалять данные Safari, чтобы не потерять сохранение.

Управление: WASD или стрелки, пробел — удар, Q — свет, E — зелье, Shift — рывок, F — взаимодействие, I — экипировка, Esc — настройки. На iPhone — экранные кнопки, горизонтальная ориентация. WebGL2 требуется для 3D, при недоступности — резервный 2D. В настройках указан графический режим.

Ограничения: модели процедурные, не студийные скелетные GLB-модели; 3D на iPhone, производительность и PWA-офлайн требуют проверки на устройстве. Сценарий не расширен.
